# 過去問ノート

入試の過去問を解いた記録（志望校・年度・科目・解いた日・点数）をつけて、点数の推移をグラフで見るためのスマホ向けアプリです。

塾の先生が担当の生徒全員の分を記録することも、生徒が自分の分だけ記録することもできます。

## できること

- 生徒ごとに過去問の記録をつける（志望校・年度・科目・解いた日・得点・満点・合格最低点）
- 志望校・科目ごとに、得点率と合格最低点の推移をグラフで見る
- 最新・平均・最高の得点率を確認する
- バックアップの書き出し・読み込み（生徒から受け取ったファイルを先生の端末にまとめることもできます）
- CSVで書き出して、Excelやスプレッドシートで開く

## データの保存について

- 記録は、アプリを開いた端末のブラウザの中（localStorage）にだけ保存されます。サーバーには送られません。
- このリポジトリは公開されていますが、公開されているのはアプリのプログラムだけです。生徒の名前や点数はここには入りません。
- ブラウザのデータを消すと記録も消えるので、ときどき「設定」からバックアップを書き出してください。
- iPhoneのSafariは、しばらく開かないWebサイトのデータを消すことがあります。「ホーム画面に追加」して使うのがおすすめです。

## 公開のしかた（GitHub Pages）

1. このリポジトリの **Settings** → 左のメニューの **Pages** を開く
2. **Build and deployment** の **Source** を「Deploy from a branch」にする
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 1〜2分待つと、`https://teta-beni.github.io/kakomonn/` で開けるようになります
